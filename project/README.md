# Emergency Blood Donor Live Network

## Overview
The **Emergency Blood Donor Live Network** is a web-based application designed to connect blood donors with patients in urgent need. The platform enables quick and efficient communication between donors and recipients, reducing delays during critical situations.

This project is built as a React capstone project with the goal of solving real-world problems using modern web technologies.

---

##  Objective
To create a system that helps users find suitable blood donors quickly based on blood group, location, and availability, especially during emergencies.
